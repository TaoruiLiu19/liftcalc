# 对拍用例

每个用例一个目录，三件套：

```
cases/<模块>/<编号>/
├─ case.json     # 输入（本系统格式）
├─ oracle.json   # 原程序输出（人工录入）
└─ diff.md       # 由 liftcalc compare 生成
```

## 录入约定

1. **标题必须对齐**：`oracle.json` 里的 `title` 必须与本系统 `checks[].title` 完全一致（空格会被忽略），否则会记为 `UNMATCHED`。
2. **单位对齐**：`value` / `limit` 填原件界面显示的单位（通常 MPa），不要自己换算。
3. **版本必填**：`source`、`captured_at` 不能空，否则半年后无法判断差异来自哪里。
4. **截图留档**：把原件界面截图放进同一目录（`screenshot` 字段写文件名）。

## 分级口径

| 分级 | 判据 | 处置 |
|---|---|---|
| `BLOCKING` | 通过/不通过结论不一致 | **必须查清**，该模块不得标记完成 |
| `HIGH` | 数值偏差 > 5% | 记录原因，多半是公式选择或取值表不同 |
| `WARN` | 偏差 1%–5% | 记录，允许保留 |
| `PASS` | 偏差 ≤ 1% | 通过 |

> 偏差裁决以**规范**为准，不以原程序为准。若原程序更保守（用了自己的简化），
> 记为"已知差异"，不回改实现。

### 双机幅度优化对照

决策量为两台固定吊机的站位及车体平面位姿 (x, y, θ)。给定车体局部吊点 aᵢ、回转中心 cᵢ，水平工作幅度为 rᵢ = ‖(x,y) + Rot(θ)aᵢ − cᵢ‖。每条轨迹按两台车的全程峰值幅度上界由大到小排序，先压低较大的值，再压低另一台。校核状态和问题数优先于幅度目标。可分别给每台吊机设硬幅度上限；自动规划只返回区间上界满足所设上限的候选。

保留原有站位采样和穿隙路线，增加车体位置与方向的格网搜索。邻接动作包括纵移、侧移、原地转动、平移同时转动，以及上述动作的反向。搜索用路径上遇到的最大采样幅度作为代价，在不同查表约束下产生候选。最终按连续区间复核。区间内平移为线性，旋转吊点偏离端点弦线的距离至多为 ‖aᵢ‖Δθ²/8（Δθ 用弧度），可据此收紧幅度上界。粗格网每 15° 设角度节点，追加的 10° 和 7.5° 格网同步缩小平移步长，三者均纳入终点角度。细格网在相同物理宽度的走廊中搜索，要求两台车的采样幅度均满足性能表负荷率限制。搜索范围、站位数和分辨率有限，结果为本次搜索的候选。连续避碰与双机协调约束参考 [Cai 等的双机规划研究](https://cindycia.github.io/publications/cai-2017-automatic/)，位姿空间和离散搜索参考 [LaValle《Planning Algorithms》](https://msl.cs.uiuc.edu/~lavalle/planning/book.pdf)。

#### 在峰值幅度受限时增加净距

规划器先找满足校核项的路线，再固定站位、吊点、起止姿态及每台车各自的峰值幅度和负荷率上界。在原有中间姿态附近，尝试提前转向、延后转向、把位姿移向相邻姿态中点或跨过冗余调姿点。每条连接都用连续区间校核器计算；在这些连接组成的有向图中优先保留全程净距下界较大的路线。拼接后重新核对全程，只有净距下界提高、每一侧的上界均满足且全段校核通过时才采用。复杂场地在局部搜索预算耗尽时保留原路线。

#### 斜穿两机空隙

在 [错位机位算例](rail-transfer-oblique.json) 中，A、B 机中心分别位于 (−1.5, −5.5) m 与 (1.5, 5.5) m。沿转运方向错开 3 m，中心距 11.40 m，小于 12 m 车长。车宽 3 m，吊件 6 t、重心居中，净距要求 0.50 m，输入假设两机全段可用钩高下限为 6 m。两机全程固定。

以两回转中心连线的垂线为 0°。车体形心第一次从一侧穿到另一侧时，车体纵轴与该垂线的夹角为 **8.4°**，形心行进方向与它的夹角为 **18.0°**。两机峰值幅度上界向上取至毫米均为 **12.511 m**，最高负荷率均为 **54.44%**，全程平面净距下界向下取至毫米为 **0.681 m**。轨迹图叠画穿越瞬间的车体，两个角分别描述车身朝向与平移方向。这个例子在上一版也能找到斜穿路线，本次扩充了斜穿候选并使角度可核图。

生成候选时，矩形车体沿两机中心连线的投影宽度为 L|sin α| + B|cos α|，其中 α 为车体纵轴相对法向的角度。在两占地矩形投影之间扣除双侧要求净距后，剩余宽度用于分配车体偏角和形心横移。该条带只用于生成一组候选，错位机位与有限占地的实际可行性由全程区间校核判断。格网搜索同时尝试纵向和横向各移动一格的斜向平移。

程序选取 A (0.77, −5.8) m、B (−0.77, 5.8) m，两机沿走廊错开 1.54 m，中心距 11.702 m，小于车长。形心首次穿过两中心连线时，车体相对法向为 11.4°，形心行进方向为 15.3°。全程限制对象为固定机位占地与障碍。对**这组机位**，起吊与落位两端已要求各机峰值至少为 √(11.77² + 0.8²) ≈ 11.797156 m。连续校核得到峰值上界 11.797324 m，相差约 0.17 mm。此数值是固定机位下的数学界差；现场放样精度、模型误差与其他站位的最优性须分别考虑。

自动站位沿起落方向试算两机一前一后的布局。对于圆形障碍和含支腿的矩形占地，将每个障碍转换为该机沿走廊不可停放的区间，合并重叠区间，再分别求两机最近的可用位置。生成避让候选时额外预留 0.12 m；最终仍按输入的净距要求复核。每个候选的机位在悬吊期间固定。选址仅覆盖已输入的占地与障碍，现场可支腿区域、地基及允许回转扇区仍需现场核对。选址与吊运路径联合考虑的研究思路可参阅 [Zhou 等，Integrated Dual-Crane Positioning and Lifting Planning](https://doi.org/10.1061/jcemd4.coeng-17533)。
